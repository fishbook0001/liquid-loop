# E5 提案：非 embedding 同义归并（别名表 + 形态归一化抽壳）

> 驱动来源：飞哥转来的一份机制派 AI 对液环的深度 critique（2026-08-25）。
> 该 critique 的诊断方向正确，但其"解法"前半句（把同义成核从检索挪到证据聚合层）**液环已有**（selfspin），本文只承接真正未实现的半句——**零 token 重叠同义的显式别名表**。
> 公理红线：本提案**零 embedding、零 LLM 推断、可解释、不降成核门槛**。任何偏离即背叛 `WHY_NO_VECTOR.md` 基石。

---

## 一、问题陈述：语义逃逸是禁向量的真阿喀琉斯之踵

`WHY_NO_VECTOR.md` 与 `faithful_e4.py` 已实证：液环用"≥2 条一致证据才结晶"抹掉单条噪声改写能力，但代价是**成核门槛建立在字符重叠上**。

`faithful_e4.py:157-176` 的盲区场景实测：

| 案例 | 输入 | 结果 |
|---|---|---|
| 字符重叠同义（禁用↔禁止↔使用） | 2 条 | 聚 1 核 → 成核 ✓ |
| 纯语序改写（判定一致时禁用向量） | 2 条 | 聚 1 核 → 成核 ✓ |
| **词汇完全不重叠同义**（"液环禁用向量检索记忆" vs "液环排斥嵌入表示方式"） | 2 条 | **0 核 → 事实流失 ✗** |

结论（`faithful_e4.py:244-246` 原话）：selfspin 是**字符重叠**聚类，非语义聚类。语义等价但用词不重叠 → 两 agent 含义一致也无法成核。

这就是 critique 点出的"你为消灭噪声幻觉，付出了语义逃逸"。

## 二、现状盘点（避免重复造轮子）

| 层 | 机制 | 覆盖 | 不覆盖 |
|---|---|---|---|
| selfspin 聚类 | `selfspin.py:24` 本地先聚类规范化，jaccard≥0.60 + 共享字≥4（`WHY_NO_VECTOR.md:125`） | 换说法但**共享核心词**的改写 | 零 token 重叠同义 |
| rar 液态召回 + liquid_reweight 黏滞唤醒 | rerank 增强（`test_rar.py:99` 中文部分重叠同义可召回） | 召回侧部分重叠 | 不是同义**归并**，不补成核洞 |
| **显式别名表** | **不存在**（全仓 grep `alias|同义词|synonym|别名表` 无独立机制） | — | — |

**定位**：E5 不是新架构，是给 selfspin 前置/并联一层**可解释的确定性别名归并**，专门吃"零 token 重叠同义"。

---

## 三、设计约束（公理安全，不可妥协）

1. **零 embedding**：一致性判定路径不引入任何向量相似度。别名归并靠显式规则 / 显式映射，不靠近邻。
2. **零 LLM 推断**：别名表与形态归一化是确定性函数，不调用模型"判断同义"。
3. **可解释**：每条归并可回溯到触发它的规则 / 映射条目（与"成核可回溯到 evidence id"同构）。
4. **不降成核门槛**：别名表只降低"识别同义"的成本，**不降低** `≥2 distinct source 支持` 的结晶门。错别名不得让单条噪声成核。

---

## 四、E5 设计

### 4.1 形态归一化层（morphology normalization）
在 selfspin 聚类前跑一道确定性清洗，抬高字符重叠命中率（仍守"字符级"，不涉语义）：
- 去停用词 / 标点归一（已有雏形，selfspin 已去虚词）
- 繁简统一、全半角统一、大小写折叠
- 词形归一：中英术语对照表（如 `embedding → 嵌入`, `vector → 向量`）——**这是别名表的最小子集**
- 形态还原：中英文形态变体折叠（复数/时态/词缀，按规则非模型）

### 4.2 显式别名表（alias map）
结构（确定性、可审查）：
```json
{
  "alias_map": {
    "液环禁用向量检索记忆": ["液环排斥嵌入表示方式", "液环不用embedding做记忆检索"],
    "稳定性公式": ["stability公式", "s/(s+2c+1)"]
  },
  "term_norm": { "embedding": "嵌入", "vector": "向量" }
}
```
- **来源**：人工 / 规则录入（curation），非自动推断。可来自已结晶 canonical 对的可解释派生（如术语对照）。
- **双向索引**：查询任一键 → 返回同义簇候选。
- **版本化 + 可审计**：每条映射带录入来源，便于回滚错别名。

### 4.3 集成点（selfspin 后、精确成核前）
```
 ingest 报告
   → 形态归一化（4.1）
   → selfspin 字符重叠聚类（已有）
   → 别名表归并（E5 新增）：把"零 token 重叠但别名表命中"的报告并入同一 canonical 候选
   → 精确成核（≥2 distinct source 支持才结晶，门槛不变）
```
别名归并不是绕过成核，是让"两 singleton 因用词不重叠而各 1 条被丢弃"的事实，能被识别为同一事实后合并 → 合计 n_reports=2 → 满足结晶门。

### 4.4 防噪声约束（关键）
- 别名表归并**仍须满足 ≥2 distinct source 支持**才成核（门槛不降）。
- 错别名风险由"别名表 curation 质量"承担，不由机制兜底——明确写进失败模式（§五）。
- 归并结果可回溯：结晶记忆带 `merged_via: alias_map:<条目id>`，与成核 evidence id 同构可追溯。

---

## 五、失败模式与缓解

| 风险 | 后果 | 缓解 |
|---|---|---|
| 错别名（误判同义） | 两条无关 singleton 合并 → 单条噪声成核 | 归并仍走 ≥2 门；别名表可审计可回滚；错别名即删条目 |
| 别名表膨胀 | curation 负担 → 维护成本 | 只收高频同义对；术语对照用规则生成，不手工堆 |
| 别名表覆盖不全 | 仍有一部分零 token 重叠同义流失 | 诚实标注覆盖率；这是"可解释的部分解"，不是"全解" |
| 形态归一过度 | 折叠掉真实差异 | 归一化只做无损等价（繁简/大小写），不做语义合并 |

## 七、验收标准

1. 合成盲区场景：零 token 重叠同义在别名表命中后成核率 > 0（原 = 0）。
2. 抗噪不退化：错别名场景下成核门槛仍 ≥2 distinct source，单条噪声不成核（faithful_e4 S4 指标不变）。
3. 公理合规：`grep` 确认 E5 路径无 embedding / 无 LLM 同义推断；归并可回溯到别名条目 id。
4. LoCoMo/LongMemEval 报告产出，含 E5 开/关对照。
